# 批量重命名 · BatchRenamer

在 Windows 资源管理器里选中一批文件，右键打开「批量重命名（预览）」，对照原名和新名，再一次完成修改。适合清理下载文件名中的网址、给照片添加前缀，或为一组音轨连续编号。

**[下载 Windows 安装包](https://github.com/aspojo/BatchRenamer/releases/latest/download/BatchRenamerSetup.exe)**

![批量重命名实际界面。左侧预览五首歌曲的原名和新名，右侧已选中“仅留汉字”规则。](docs/preview.png)

## 安装与使用

1. 下载并运行 `BatchRenamerSetup.exe`。安装程序为当前用户添加开始菜单快捷方式和文件右键菜单，无需管理员权限。
2. 在资源管理器里选中文件。Windows 10 右键选择 **批量重命名（预览）**。Windows 11 右键进入 **显示更多选项 → 批量重命名（预览）**。也可以从开始菜单打开工具，再拖入文件。
3. 选择右侧的一种规则，在左侧查看每个文件的新名。取消勾选可跳过某个文件，点击行末的铅笔可单独修改名称。每次仅执行当前选项卡的规则，文件扩展名会保留。
4. 选择 **原地重命名** 或 **另存为副本**，然后点击右下角的执行按钮。副本保存在原文件所在的文件夹。当前窗口内可点 **撤销上次操作**，恢复原名或移除刚创建的副本。

## 命名示例

| 规则 | 如何设置 | 原文件名 | 新文件名 |
| --- | --- | --- | --- |
| 删除 | 点击 **仅留汉字** | `00 - 冰箱上那张纸 - usesuno.com.flac` | `冰箱上那张纸.flac` |
| 替换 | 查找 `初稿`，替换为 `终稿` | `项目简报-初稿.docx` | `项目简报-终稿.docx` |
| 插入 | 前缀填 `旅行-` | `海边.jpg` | `旅行-海边.jpg` |
| 编号 | 选 **文件名前**，从 `1` 起排，设为 `2 位` | `开场.wav` | `01 - 开场.wav` |

编号按列表中勾选文件的顺序生成，点击「原文件名」表头可切换排序。如果预览中出现重名、无效字符或同名文件已存在，先修改对应行，再执行。

## 从源码构建

在 Windows 上准备 PowerShell、.NET Framework 4.8，以及 Visual Studio Build Tools 的 **使用 C++ 的桌面开发** 工作负载。构建脚本会调用 .NET Framework 自带的 C# 编译器和 WPF 程序集，并使用 MSVC x86/x64 工具与 Windows SDK 编译资源管理器扩展。

在仓库根目录运行以下命令。

```powershell
.\build.ps1
.\dist\BatchRenamerSetup.exe
```

`dist\BatchRenamerSetup.exe` 是包含主程序及 32 位和 64 位右键菜单扩展的安装包。`dist\BatchRenamer.exe` 可独立启动，用于拖入或添加文件。卸载时，在 Windows 的应用列表中找到「批量重命名」并选择卸载。
